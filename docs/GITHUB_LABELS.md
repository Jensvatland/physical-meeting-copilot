# Recommended GitHub labels

Configure these in the repository **Settings → Labels** (or via `gh label create`). Keep the set small.

| Label | Color suggestion | Purpose |
|-------|------------------|---------|
| `good first issue` | `#7057ff` | Well-scoped starter tasks |
| `help wanted` | `#008672` | Extra attention appreciated |
| `bug` | `#d73a4a` | Something broken |
| `feature` | `#a2eeef` | New capability |
| `experiment` | `#f9d0c4` | Research / exploratory work |
| `documentation` | `#0075ca` | Docs / DX |
| `audio` | `#c5def5` | Capture, VAD, hardware |
| `STT` | `#bfdadc` | Speech-to-text adapters |
| `diarization` | `#d4c5f9` | Speaker labeling |
| `translation` | `#fef2c0` | MT / glossary |
| `AI` | `#e99695` | Agent / intelligence behavior |
| `models` | `#fad8c7` | Model packaging / selection |
| `MCP` | `#bfd4f2` | MCP server / resources / tools |
| `integration` | `#d1f0d1` | Host or system bridges |
| `iOS` | `#f0e6ff` | iPhone client |
| `iPadOS` | `#e6f0ff` | iPad client |
| `macOS` | `#eeeeee` | Mac tooling / capture |
| `privacy` | `#5319e7` | Consent, retention, biometrics |
| `security` | `#b60205` | Auth, threat model, secrets |
| `performance` | `#fbca04` | Latency / resource use |

Default GitHub labels like `duplicate`, `invalid`, and `wontfix` can stay. Prefer `feature` over `enhancement` for consistency with issue templates.
